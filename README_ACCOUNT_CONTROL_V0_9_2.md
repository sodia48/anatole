# Anatole v0.9.2 — Sécurité et contrôle du compte

Cette version ajoute la modification du nom affiché, le changement de mot de passe avec fermeture des autres sessions, l’export JSON des données et la suppression définitive du compte.

Le courriel reste l’identifiant de connexion. La suppression efface le compte et l’espace synchronisé dans PostgreSQL; les données locales du navigateur ne sont pas supprimées automatiquement.
