# Déploiement Anatole Mobile v0.7.4

1. Décompresser le PATCH à la racine du dépôt Anatole.
2. Accepter les remplacements.
3. Commit et push sur `main`.
4. Redéployer uniquement Vercel.
5. Désactiver `Use existing Build Cache` pour ce premier déploiement.
6. Tester sur un téléphone réel :
   - `/cockpit` : les 60 titres, symbole et variation;
   - `/etf` : carte mobile en tuiles, sans treemap;
   - `/screener`, `/comparateur`, `/terminal`, `/portefeuille`;
   - `/focus/RY`, puis états financiers;
   - `/etf/XIC`, puis participations.

Aucun redéploiement Render n'est requis.
