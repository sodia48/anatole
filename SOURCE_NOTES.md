# Sources de données — Calendrier provincial v1.5.1

Le principe est `province-first` : source provinciale officielle lorsqu'un calendrier stable existe; Statistique Canada uniquement pour les publications qui contiennent réellement une ventilation provinciale.

Québec : Statistique Québec — calendrier des principaux indicateurs économiques.
https://statistique.quebec.ca/fr/produit/tableau/calendrier-de-diffusion-principaux-indicateurs-economiques

Ontario : Ontario Economic Accounts — calendrier/échéances publié dans le Budget 2026.
https://budget.ontario.ca/2026/chapter-2.html

Saskatchewan : Saskatchewan Bureau of Statistics — calendrier 2026-27.
https://publications.saskatchewan.ca/api/v1/products/86689/formats/156260/download

Colombie-Britannique : BC Stats.
https://www2.gov.bc.ca/gov/content/data/statistics/economy

Alberta : Alberta Economic Dashboard.
https://economicdashboard.alberta.ca/

Manitoba : Manitoba Bureau of Statistics.
https://www.gov.mb.ca/mbs/

Nouveau-Brunswick : tableau de bord économique provincial.
https://www3.gnb.ca/FTB-FCT/?lang=en

Nouvelle-Écosse, Île-du-Prince-Édouard et Terre-Neuve-et-Labrador : pages statistiques/financières provinciales présentes dans `provincial_macro.py`, complétées par le volet provincial StatCan.
