# Anatole v0.7

Cette version active les quatre dernières entrées de la navigation actuelle :

- **Portefeuille** : positions, P&L, performance vs TSX, allocation, risque et concentration.
- **Alertes** : prix, variation, RSI, momentum, volume relatif et score Anatole.
- **Assistant** : lecture contextuelle du marché, des titres, comparaisons, portefeuille et qualité.
- **Qualité des données** : couverture, fraîcheur, caches, retries, échecs upstream et routes.

Consultez `DEPLOY_V0_7.md` avant le déploiement et `VALIDATION_V0_7.md` pour les contrôles exécutés.
